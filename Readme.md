# **Binary-Tree-Visualization** - Animated GUI

**Interactive desktop app** for **AVL Trees** with **animation**, **search visualization**, and **auto-balancing**. Perfect DSA portfolio project!
---
## ✨ **Features**
| Feature                | Icon  | Status                  |
| ---------------------- | ----- | ----------------------- |
| AVL Insert + Rotations | 🔵   | ✅ Auto-balanced        |
| Search Animation       | 🔍   | ✅ Gold path highlight  |
| Dark/Light Themes      | 🌙☀️ | ✅ Pro toggle           |
| PNG Export             | 📸   | ✅ High-res screenshots |
| Balance Factors        | 📊   | ✅ Live BF display      |
| Traversals             | 📈   | ✅ Inorder popup        |
| Random Trees           | 🎲   | ✅ Perfect 30-node AVL  |
---
## 🚀 **Run (1 minute)**
```bash
# Pure Python - NO pip needed!
cd Binary-Tree-Visualization
pip install -r requirements.txt
python main.py
```
---

**Demo Flow:**
```
1. Insert: 50 → 30 → 70 → 20 → 80
   ↓ Watch rotations balance tree!

2. Search: 20 
   ↓ Gold path highlights search!

3. Random → Instant perfect AVL tree
```
